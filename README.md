# 鸡场

原生 Android 订阅与节点管理器，面向 Mihomo 配置。应用只管理数据并生成 Mihomo YAML，不内置代理内核，也不接管 Android VPN。

## 当前功能

- 本机添加和刷新 HTTP(S) 订阅；节点可粘贴或扫码导入 Mihomo/Clash YAML、Base64、常见节点分享 URI 与基础 Surge 节点行。扫码使用 Google Play 服务，设备不支持时仍可粘贴导入。
- 概览、资源、规则、分享四个入口；资源内分为订阅、节点和模板，配置仍可创建、复制、切换、重命名和删除。
- 订阅和节点库共享；每份配置独立选择订阅、节点、规则、地区分组和导出选项。
- 节点支持搜索、来源/协议/启用状态/地区筛选、批量启停、编辑和按当前配置调整地区归属。
- 规则页整合规则、策略组、规则集、子规则和校验；支持从配置模板应用规则集及关联路由规则、本机下载远程规则集和编写内嵌规则集。策略组可指定代理成员并批量关联规则目标，规则冲突以非阻断警告提示。
- 规则管理支持按内容、类型和策略筛选，多选删除、排序、编辑及规则问题定位；编辑器保留高级参数和导入的原始组合表达式，导出前检查无效目标与缺失引用，MATCH 兜底固定最后。
- 自动按地区筛选节点并生成策略组；导出可内嵌节点或引用 Mihomo 订阅。
- 配置编辑增加 Mihomo 基础设置：通用模式与监听端口、局域网访问、控制器、DNS、TUN、嗅探和 NTP；设置按配置文件隔离，保存后实时进入 YAML 预览、下载和局域网分享。
- 高级 YAML 可查看、编辑模板中未被鸡场表单托管的字段，包括 DNS/TUN 等区块内未由表单显示的子项；安全解析并阻止覆盖由可视化编辑器管理的字段。
- 常用节点参数使用安全 YAML 编辑，保留 TLS、传输层、布尔值、列表和嵌套选项；新增 SSR URI 解析与 Mihomo 导出支持。
- 分享页显示导出状态，可预览和下载当前生成的 Mihomo YAML，也可通过局域网链接和二维码分享；规则问题可直接跳转到校验页。
- 模板页可从 HTTP(S) 链接下载 Mihomo YAML 并保存到本机模板库；可以预览、重命名、导出或基于模板创建可编辑配置。模板中的 DNS、TUN 及其他未托管顶层字段会在生成时保留，远程 URL 不会保存。
- 模板中的空白或占位机场地址可按配置绑定到资源页的 Mihomo 订阅；引用导出使用绑定订阅地址，内嵌导出移除占位 provider。模板已有地区筛选组时沿用模板分组，避免重复生成。
- 局域网分享使用当前配置与导出选项，支持动态更新和随时停止；二维码只包含带随机访问令牌的局域网链接，停止分享后失效。
- 在开启分享的同一台手机上导入时，建议使用“下载配置”，再从 `Downloads/鸡场` 选择文件；局域网链接主要用于其他设备。
- 分享端直接返回固定长度的 Mihomo YAML，不启用 HTTP 压缩；使用 `inline` 文件处置提示和配置文件名，支持客户端通过 `HEAD` 获取文件元数据及直接导入 URL。
- 分享地址从 Android 当前 Wi-Fi 或以太网连接中读取；访客网络、客户端 VPN 和 AP 隔离可能阻止局域网设备互访。
- 导航和分段控件使用鸡场自有的 AGSL GPU 液态玻璃，包括局部背景采样、微折射、高光与可调透明度，配置内容保持清晰可读。
- 二维码由 ZXing Core 生成；其 Apache-2.0 许可证及上游随附的 jai-imageio 声明随应用一同分发，见 `app/src/main/assets/licenses/ZXing-LICENSE.txt`。
- 应用图标以啄向路由节点的小鸡表现鸡场的订阅与节点管理，使用 Android 自适应图标。
- 所有数据通过 Room 保存在本机，不启用云同步或第三方转换服务。

目前 URI 解析覆盖 SS、SSR、VMess、VLESS、Trojan、Hysteria、Hysteria 2、TUIC、AnyTLS、SOCKS5 和 HTTP。YAML 输入保留节点字段；无法识别的行会计入跳过数。配置生成器仅输出一份 Mihomo 格式，不按 Clash 系 App 分流。

## 获取应用

请从 GitHub Releases 下载并安装 Android APK。本仓库发布应用源码与安装包，不附带构建脚本。

当前发布版为鸡场 0.9.3，要求 Android 13（API 33）或更高版本，以启用 Android 图形着色语言（AGSL）玻璃渲染。

## 局域网分享

每次开启分享都会生成新的随机路径令牌；链接和二维码只绑定当前局域网接口，停止分享或系统关闭服务后失效。鸡场会以前台服务保持分享运行，切到后台时请保留状态栏中的分享通知。系统结束进程、厂商省电策略或网络切换仍可能中断服务；重新开启后会生成新链接。若在本机导入，建议下载配置文件并从 `Downloads/鸡场` 选择，局域网链接用于同网其他设备。链接和二维码都是访问凭据，请只发给可信对象。传输为 HTTP，适用于可信局域网；不应在公共 Wi-Fi 上分享。
